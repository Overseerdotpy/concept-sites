Amberline · logo

The l is the line.

The l in "line" is set in solid amber: the line money travels along to reach you. It still reads as a letter, so the name is never harder to read for carrying the brand.

Primary

Ink letters with the amber l, on paper or white. The "a" is single-story, cut from the same letterforms as the rest of the word.

Monogram

The single-story "a" with its stem in amber. In the animation, this stem leaves the "a", travels along the word, and becomes the "l".

Reversed and one color

On forest or any dark ground, the letters turn paper-light and the l stays amber. Where only one color is possible, the l is drawn slightly heavier so the idea survives without amber.

Reversed, for dark backgrounds

One color: fax, stamps, engraving, black-and-white print

Small sizes

Below about 32px tall, use the small cut: heavier strokes and slightly looser spacing, so the amber l doesn't thin out.

In motion

The amber l can fill from the bottom like a meter, for loading screens and the moment a payment lands.

Use this instead of a generic spinner anywhere Amberline is waiting on money: syncing a bank, confirming a payout.

Rules

Clear space

Keep empty space around the logo at least the height of the letter "a" on every side.

Minimum size

Primary cut down to 32px tall; below that use the small cut. Never smaller than 14px.

Always lowercase

Never capitalize the wordmark. In running text, write the name as "Amberline."
